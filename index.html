Rates & defaults
Passcode

The passcode locks this app on your device(s). It is not a substitute for a secured server — see the data note in Help before storing many real customer records in the cloud.

Data

Everything is stored in this browser (localStorage). Download a backup regularly until cloud sync is enabled.

How it works

New request → Scheduled → Evaluated → Parts ordered → Parts arrived → Completed. Set a job's status as it moves along; the map colours each pin by status so parts-arrived jobs (green) stand out as ready to go back out.

Paste text/email: top-right button — paste a customer SMS or email and the app pulls out name, phone, address and the problem into a new draft you confirm.

Scheduling: add one or more appointments to a job (evaluation, repair, follow-up). Each has an Add to calendar button (downloads an .ics that imports into Google/Outlook/Apple Calendar) and a Google Calendar quick-add link.

Quote vs expenses: the Customer estimate section (labour + parts) is what you share with the customer. Travel expenses are kept separate and only appear in the company expense claim — never on the customer quote.

Copy for ServiceBench / Salesforce: the 📋 button beside each field copies just that value.

⚠️ Data & privacy note

This build stores customer names, addresses and phone numbers locally in your browser only, behind the passcode. Cloud sync (phone ↔ desktop) is wired but off until a secured Firebase project (with sign-in rules) is set up — a passcode alone on a shared database would leave the data readable. Ask to turn on secured sync when you're ready.
